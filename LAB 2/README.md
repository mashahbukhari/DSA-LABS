## Static and Dynamic Arrays, Pointers and Dynamic Memory Allocation

This lab focuses on arrays, pointers, dynamic memory allocation, and proper memory management in C++.

### Tasks

**Task 1 – Static Array and Pointers**
Stores sales for five days using a fixed-size array and accesses the values using pointers. It also calculates the total and updates the third day's sales.

**Task 2 – Dynamic Array**
Creates a dynamic array for student marks based on the number of students entered by the user. It calculates the total, average, and number of passing students, then safely releases the memory.

**Task 3 – 2D Array and Row Pointers**
Uses a two-dimensional array with a row pointer to store sales for two branches over three days. It calculates totals for each branch and each day.

**Task 4 – Dynamic 2D Array**
Creates a dynamic 2D marks array using row pointers and calculates each student's total. It also identifies the student with the highest total and properly frees all allocated memory.

**Task 5 – Dynamic Array Expansion**
Expands a dynamic marks array by creating a larger block, copying the old values, and adding a new mark. The old memory is then released safely.

**Task 6 – Pointer and Memory Errors**
Identifies and fixes common dynamic memory errors such as out-of-bounds access, incorrect deletion, and dangling pointers. The corrected program reads and displays three integers safely.
